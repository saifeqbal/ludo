LudoJS Architecture & Documentation

                    
LudoJS is a zero-dependency, object-oriented JavaScript library designed for building robust Ludo applications, multiplayer board games, and AI simulations.

                


                

                    
1. Core Classes Overview

                    

                        

                            
LudoGame

                            
Main engine managing game lifecycle, turn queue, event emitter (`on`, `off`, `emit`), and victory detection.

                        

                        

                            
Board

                            
Manages 52 track cells, home paths, safe star coordinates, and collision / capture rules.

                        

                        

                            
Player & Pawn

                            
Manages player type (HUMAN vs CPU), 4 individual pawns per player, step tracking (-1 to 56), and status.

                        

                        

                            
AIController

                            
Heuristic bot engine that evaluates capture opportunities, base unlocks, and optimal pawn progression.

                        

                    

                


                

                    
2. Quickstart Code Example

                    
// Initialize LudoJS Game instance
const game = new LudoGame({
    players: ['RED', 'GREEN', 'YELLOW', 'BLUE'],
    aiPlayers: ['GREEN', 'YELLOW', 'BLUE']
});

// Listen to events
game.on('roll', (data) => console.log(`${data.player} rolled ${data.roll}`));
game.on('move', (data) => console.log(`Pawn moved:`, data));
game.on('win', (data) => console.log(`Winner: ${data.winner}`));

// Start game and roll dice
game.start();
const roll = game.rollDice();
const movable = game.getMovablePawns(roll);
if (movable.length > 0) {
    game.movePawn(movable[0]);
}
